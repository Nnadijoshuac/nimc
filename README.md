# NIN Support Atlanta

This project is a static, front-end-only informational website for NIN support and enrolment guidance.

## Run locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Start the site:
   `npm run dev`

## Notes

- No customer form inputs or data collection flows are included.
- The app does not depend on any backend services.
- The public site is intentionally informational-only.
